# Introduction à PHP 7 : Scripts Console et Services Web

📘 **Accéder à la documentation du cours :** [https://stahe.github.io/php7-juillet-2019/](https://stahe.github.io/php7-juillet-2019/)

---

Ce projet propose une collection de scripts console en PHP 7 illustrant différents domaines du langage et de son écosystème.

## Contenu du dépôt

Les exemples couvrent les thématiques suivantes :
- **Structures du langage**
- **Accès aux fichiers**
- **Accès aux bases de données**
- **Accès au réseau internet**

## Approche Web

La programmation web est ici abordée sous l'angle des **services web**. Dans ce contexte, nous désignons par "service web" toute application produisant du texte brut (serveurs de données), par opposition aux serveurs de pages web qui génèrent un mélange de HTML, CSS et Javascript.

### Concepts clés abordés
Le projet explore des concepts web fondamentaux utilisés dans la programmation classique :
- Protocole HTTP
- Formats de réponse JSON ou XML
- Gestion de session
- Authentification
